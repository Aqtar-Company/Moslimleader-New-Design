# reels-studio — خط إنتاج ريلز آلي

كاركتر بروفايل + سكريبت عربي → ريل ٩:١٦ جاهز للنشر.

```
سكريبت عربي ──► Claude يقسّمه لمشاهد ──► Veo يولّد كل مشهد ──► ffmpeg يركّب
                 + يكتب برومبتات Veo       (صور مرجعية للتثبيت)      + خاتمة + سبتايتل
```

---

## قرار المعمار: ليه مش Google Flow؟

| | Flow (flow.google) | Veo عبر Gemini API ← **المستخدم هنا** |
|---|---|---|
| API | ❌ مفيش API رسمي | ✅ برمجي بالكامل |
| أتمتة وجدولة | ❌ مستحيل | ✅ cron + طابور |
| الرصيد | credits الاشتراك | فوترة منفصلة — **رصيد Flow لا يتحوّل لرصيد API** |
| الموديل | Veo 3.1 | Veo 3.1 (نفسه) |

Flow استوديو يدوي. الاستدامة محتاجة API.

## بنية الريل والتكلفة

الريل الافتراضي **١٥ ثانية** = ١٠ ثواني AI + ٥ ثواني خاتمة:

| الجزء | المدة | إزاي | التكلفة |
|---|---|---|---|
| مشاهد AI | ١٠ث | كليبين من Veo (٤ث + ٦ث) | **$1.00** |
| خاتمة اللوجو | ٥ث | كارت ثابت بـ ffmpeg | **$0.00** |
| صوت متصل | ١٥ث | تراك واحد على الريل كله | $0.00 |

**التوفير في التفاصيل:** Veo بياخد `durationSeconds` من `[4, 6, 8]` وبيحاسب على
الثانية **المطلوبة**. طلب `4+6` لعشر ثواني بيكلّف ١٠ ثواني — بينما `8+8` وقص محلي
بيكلّف ١٦. المخطط في `planClips()` بيختار أقل تركيبة هدراً تلقائياً.

```
 8ث → [8]       = $0.80        18ث → [4,6,8]   = $1.80
10ث → [4,6]     = $1.00        20ث → [4,8,8]   = $2.00
15ث → [8,8]     = $1.60        30ث → [6,8,8,8] = $3.00
```

`REELS_TIER=fast` للتجارب، `std` للنسخة النهائية (٤ أضعاف السعر).

## التركيب

```bash
cd reels-studio
npm install
cp .env.example .env      # واملا المفاتيح
```

**متطلبات النظام** (CentOS/RHEL 9 — السيرفر بتاعنا):

```bash
dnf install -y epel-release
dnf install -y ffmpeg                          # المونتاج
dnf install -y google-noto-sans-arabic-fonts   # السَبتايتل العربي
fc-cache -f
```

> من غير الخط العربي، السَبتايتل بيطلع حروف مقطّعة **من غير أي رسالة خطأ** —
> fontconfig بيرجّع خط بديل في صمت. `doctor` بيكشف الحالة دي.

**المفاتيح:** `GEMINI_API_KEY` من [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
مع تفعيل الفوترة، و`ANTHROPIC_API_KEY` لتقسيم المشاهد.

```bash
node src/cli.mjs doctor    # بيفحص كل حاجة قبل ما تصرف مليم
```

## الاستخدام

### ١. اعمل الكاركتر

```bash
node src/cli.mjs new-character ameen
```

بعدين — **ودي أهم خطوة في الفلو كله**:

1. عدّل `characters/ameen/profile.json` (الوصف بالإنجليزي)
2. حطّ **من ١ لـ ٣ صور** للشخصية في `characters/ameen/refs/`

> ⚠️ من غير الصور المرجعية دي، كل ريل هيطلع بوش مختلف مهما كان الوصف دقيق.
> **الصور هي اللي بتثبّت الشخصية، مش النص.** مواصفاتها: وجه واضح، إضاءة كويسة،
> خلفية بسيطة، زوايا مختلفة (أمامي / ثلاثة أرباع / نص جسم).

### ٢. اكتب السكريبت

```bash
node src/cli.mjs new-script episode-01
```

كلام عربي عادي — مش محتاج تقسّمه لمشاهد، الفلو بيعمل كده. خلّيه في حدود
٢٥ كلمة للعشر ثواني، وابدأ بأقوى جملة.

### ٣. جرّب من غير صرف

```bash
node src/cli.mjs make ameen episode-01 --dry-run
```

بيطبع برومبتات Veo بالظبط زي ما هتتبعت. **صفر تكلفة.** راجعها الأول.

### ٤. ولّد

```bash
node src/cli.mjs make ameen episode-01
```

الناتج في `out/<التاريخ>-ameen-episode-01/`:

```
final.mp4        ← الريل جاهز للنشر
subtitles.srt    ← ملف ترجمة منفصل للرفع
voiceover.txt    ← نص التعليق الصوتي
manifest.json    ← حالة الريل والصرف الفعلي
clips/           ← كليبات Veo الخام
```

## الاستدامة: التشغيل المستمر

```bash
node src/cli.mjs enqueue ameen episode-02
node src/cli.mjs enqueue ameen episode-03
node src/cli.mjs run-queue --limit 2
```

جدولة يومية على السيرفر:

```bash
cp ops/reels-cron.sh /etc/cron.daily/reels-studio
chmod +x /etc/cron.daily/reels-studio
```

السكربت فيه `flock` — تشغيلين متوازيين مستحيل، فمفيش صرف مضاعف على نفس المهمة.
والمهمة الفاشلة بتتسجّل `failed` مش `pending`، فالـ cron مابيفضلش يكررها ويحرق فلوس.

## حمايات التكلفة

| الحماية | السلوك |
|---|---|
| `REELS_MAX_COST_USD` | بيتحقق **قبل** أي صرف، ومرة تانية بعد كل مشهد |
| المانيفست | كل مشهد اتولّد بيتسجّل — إعادة التشغيل بتتخطّاه مجاناً |
| `--dry-run` | يطبع الطلبات كلها من غير استدعاء API |
| `enqueue` | بيتحقق إن الكاركتر والسكريبت موجودين قبل ما يدخل الطابور |

استئناف ريل وقف في النص:

```bash
node src/cli.mjs make ameen episode-01 --resume 2026-09-11-ameen-episode-01
```

## ملاحظات معمارية

**مصدر واحد للحقيقة في طلب Veo.** كل الطلب بيتبني في `buildVeoRequest()`
(`src/steps/generate.mjs`). لو Google غيّرت أسماء الحقول، ده الموضع الوحيد
اللي بيتعدّل. شوفه بـ `--dry-run`.

**السَبتايتل ASS مش SRT.** بنولّد ملف ASS بدقة مرجعية صريحة (`PlayResX/Y`).
لو سِبنا ffmpeg يحوّل الـ SRT، بيفترض دقة ٣٨٤×٢٨٨ وقيم البكسل بتتفسّر في
مقياس تاني — والنتيجة سَبتايتل ضخم فوق الشاشة بدل ما يكون تحت.

**ترتيب وسائط ffmpeg.** `-stream_loop -1` لازم يسبق **ملف الموسيقى** تحديداً.
لو سبق الفيديو، الموسيقى بتقف عند نهايتها والخاتمة بتيجي في سكوت.

**بلوك الكاركتر ثابت بالحرف.** `characterBlock()` بيولّد نفس النص بالظبط في
كل برومبت مشهد وفي كل ريل. أي تعديل فيه بيغيّر شكل الشخصية في كل الريلز
الجاية — عدّله بحذر.

## استكشاف الأعطال

| العَرَض | السبب | الحل |
|---|---|---|
| الوجه بيتغير كل ريل | مفيش صور مرجعية | حطّ ١-٣ صور في `characters/<slug>/refs/` |
| سَبتايتل بحروف مقطّعة | الخط العربي مش متثبت | `dnf install -y google-noto-sans-arabic-fonts && fc-cache -f` |
| `مفيش فيديو في الرد` | فلتر محتوى Veo رفض البرومبت | بسّط وصف المشهد في `manifest.json` وشغّل `--resume` |
| الخاتمة خلفية سادة | اللوجو مش موجود | حطّه في `assets/logo.png` |
| الموديل رفض المدة | إصدار Veo بياخد ٨ث بس | بيتعامل تلقائياً (ينزل لـ ٨ث ويقص) — بس التكلفة بتعلى |
| `التكلفة بتتخطى السقف` | الحارس اشتغل | ارفع `REELS_MAX_COST_USD` أو قلّل `REELS_VIDEO_SECONDS` |
