# مَدَد | MADAD

**Mobile AI for Disconnected Academic Development**
ذكاء اصطناعي متنقل لدعم التطوّر التعليمي عند انقطاع الاتصال.

المرحلة الأولى: **برنامج على لابتوب يعمل دون إنترنت**، ويفتحه الأطفال من هواتفهم عبر
شبكة الواي فاي المنزلية (الراوتر يكفي، ولا يحتاج اتصالًا بالإنترنت).

```
هاتف الطفل ──Wi‑Fi محلي──►  لابتوب
                             ├─ run.py      خادم مَدَد (Python فقط)
                             ├─ curriculum/ الدروس المراجَعة (Markdown)
                             └─ Ollama      نموذج Gemma 3 أو Qwen
```

## الفكرة الأساسية: النموذج لا يشرح إلا من الكتاب

النموذج الصغير قد يخطئ. لذلك مَدَد لا يعتمد على معلومات النموذج العامة:

1. **يبحث أولًا في الدروس.** كل سؤال يُبحث عنه في `curriculum/`.
2. **لا درس = لا نموذج.** إذا لم يجد درسًا مناسبًا يرد برسالة ثابتة «هذا ليس في دروسي»
   **ولا يستدعي النموذج أصلًا** — فلا فرصة للتأليف.
3. **يشرح من المقتطفات فقط** ويذكر رقم المصدر `[1]`، وتظهر تحت كل إجابة بطاقة الدرس
   الذي أُخذت منه، يفتحها الطفل ليقرأ النص الأصلي.
4. **كل درس عليه علامة مراجعة.** `reviewed: false` يظهر للطفل «غير مراجَع»، و
   `--only-reviewed` يخفي كل ما لم يراجعه معلم.
5. **سجل محلي** لكل سؤال وإجابة في `logs/` ليقرأه الأب أو المعلم (لا يغادر الجهاز؛
   `--no-log` لإيقافه).

ثلاث طرق للإجابة يختارها الطفل: **📖 اشرح لي** · **💡 ساعدني بتلميح** (لا يعطي الحل،
يقوده إليه) · **✏️ اختبرني** (3 أسئلة اختيار من متعدد من الدرس).

## التشغيل

المتطلبات: **Python 3.9+** و **[Ollama](https://ollama.com)**. لا توجد مكتبات تُثبَّت بـ pip.

```bash
# مرة واحدة فقط، والإنترنت متاح:
ollama pull gemma3:4b          # ~3.3 GB — الاختيار الافتراضي للابتوب 16GB
# بدائل للمقارنة:
ollama pull qwen2.5:3b         # أخف
ollama pull gemma3:1b          # للأجهزة الضعيفة (جودة العربية أقل — اختبرها)

# بعد ذلك، دون إنترنت:
cd madad
python3 run.py                 # أو: python3 run.py --model qwen2.5:3b
```

يطبع البرنامج عنوانين:

```
  على هذا الجهاز:   http://localhost:8080
  من هواتف البيت:   http://192.168.1.23:8080
```

افتح العنوان الثاني من أي هاتف على نفس الواي فاي. على ويندوز قد يسأل الجدار الناري
عن السماح لـ Python بالشبكة الخاصة — اختر «سماح».

| الخيار | المعنى |
|---|---|
| `--model` | اسم النموذج في Ollama (افتراضي `gemma3:4b`) |
| `--port` | المنفذ (افتراضي 8080) |
| `--only-reviewed` | إخفاء الدروس غير المراجَعة |
| `--min-coverage` | مدى صرامة رفض الأسئلة خارج المنهج (افتراضي 0.34) |
| `--no-log` | عدم حفظ سجل الأسئلة |

## إضافة المناهج

كل درس ملف Markdown في `curriculum/<الصف>/<المادة>/<الدرس>.md`:

```markdown
---
title: الكسور
grade: الصف الرابع الابتدائي
subject: رياضيات
source: كتاب الرياضيات، الفصل الدراسي الأول، ص 40
reviewed: true
reviewer: أ. فلان
---

## البسط والمقام
...
```

- كل عنوان `## ` قسم مستقل؛ هذا ما يُعطى للنموذج، فاجعل كل قسم عن فكرة واحدة.
- الدروس الأربعة الموجودة الآن **أمثلة توضيحية كتبها فريق مدد وليست من الكتاب
  الوزاري** — تُستبدل بالمنهج المعتمد، ويراجعها معلم قبل تغيير `reviewed` إلى `true`.
- `curriculum/synonyms.txt`: كلمات الأطفال (والعامية) ومقابلها في الكتاب، مثل
  `سحاب سحب غيم`. إذا وجدت في السجل سؤالًا صحيحًا رفضه مَدَد، أضف سطرًا هنا.

## الاختبار قبل أي إطلاق

```bash
python3 -m unittest discover -s tests       # اختبارات الكود (لا تحتاج نموذجًا)
python3 eval/run_eval.py                    # هل يجد الدرس الصحيح؟ هل يرفض ما ليس في المنهج؟
python3 eval/run_eval.py --llm              # يولّد الإجابات بالنموذج ويحفظها في eval/report-*.json
python3 eval/run_eval.py --llm --model qwen2.5:3b   # نفس الأسئلة على نموذج آخر للمقارنة
```

`eval/questions.json` مجموعة الأسئلة: لكل سؤال الدرس المتوقع، أو `"expect": "refuse"`
لسؤال خارج المنهج. الفحص الآلي لإجابات النموذج مجرد فحص سريع (هل ذكر الكلمة المتوقعة؟
هل ذكر المصدر؟) — **الاختبار الحقيقي أن يقرأ معلم ملف `report-*.json`** ويحكم على كل
إجابة: صحيحة؟ مناسبة لسن الطفل؟ بلا معلومة من خارج الدرس؟

الحالة الآن: **17/17** في البحث والرفض على الدروس التجريبية. لم تُختبر إجابات
النماذج الفعلية بعد — هذه الخطوة التالية على لابتوب عليه Ollama.

## البنية

```
madad/
  run.py               نقطة التشغيل
  engine/
    arabic.py          توحيد الهمزات والتاء المربوطة والتشكيل والأرقام، وكلمات السؤال بالعامية
    curriculum.py      قراءة الدروس وتقسيمها
    retrieval.py       بحث BM25 + المرادفات (بلا مكتبات وبلا ملفات فهرس)
    tutor.py           قواعد التأسيس على المنهج، أوضاع الإجابة، السجل
    ollama.py          الاتصال بـ Ollama
    server.py          خادم الشبكة المحلية
  web/index.html       الواجهة (ملف واحد، بلا أي مورد من الإنترنت)
  curriculum/          الدروس + synonyms.txt
  eval/                أسئلة التقييم وأداته
  tests/               اختبارات الوحدة
```

## الطريق من هنا

1. **الآن — النموذج الأول (لابتوب):** تشغيل `eval --llm` على gemma3:4b و qwen2.5:3b
   ومقارنة جودة الشرح بالعربي، وإدخال منهج صف واحد كاملًا ومراجعته.
2. **تحسين البحث:** إضافة بحث دلالي (embeddings عبر Ollama، مثل `bge-m3`) بجانب BM25،
   لأسئلة الأطفال التي لا تشترك مع الكتاب في أي كلمة.
3. **الصندوق المنزلي:** نفس الكود بلا تغيير على جهاز صغير (mini PC) يعمل كنقطة واي فاي
   بنفسه، ويبدأ مَدَد تلقائيًا عند التشغيل. تُضاف حسابات للأطفال ولوحة للأب تعرض السجل.
4. **التابلت المستقل:** Gemma 3n على الجهاز نفسه؛ يحتاج إعادة كتابة للتشغيل على
   Android، والمناهج والتقييم ينتقلان كما هما.
